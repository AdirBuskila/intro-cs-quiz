# מערכים ויעילות

## מה המבחן שואל
כתיבת פונקציה על מערך שמקבלת `arr` ו-`size`: ספירה, חיפוש, בדיקת תכונה (ממוין, פלינדרום, תקין), או חישוב עם דרישת סדר גודל, למשל `O(n)` במקום `O(n^2)`. השאלה המבדילה היא איך חוסכים זמן: מערך ספירה, שני מצביעים, או מעבר יחיד.

## הרעיונות המרכזיים
- מערך הוא רצף איברים באותו טיפוס. האינדקסים `0` עד `size-1`. C לא בודקת גבולות.
- `a[i]` זהה ל-`*(a + i)`, ושם המערך הוא כתובת האיבר הראשון.
- אתחול חלקי: `int a[5] = {7};` מציב 7 באיבר הראשון ואפס בשאר. `{0}` מאפס הכול.
- אי אפשר להשים מערך למערך (`b = a`) ואי אפשר להשוות מערכים עם `==`. עוברים על האיברים.
- `sizeof(a) / sizeof(a[0])` נותן את מספר האיברים, אבל רק במקום שבו `a` הוא באמת מערך, לא פרמטר.
- יעילות: מערך ספירה (`count[v]++`) מחליף חיפוש מקונן כשטווח הערכים קטן וידוע. שני מצביעים (קצה מול קצה) עוברים על מערך ממוין ב-`O(n)`.

## תבניות C מדויקות
```c
/* היפוך מערך במקום */
for (int i = 0, j = size - 1; i < j; i++, j--) {
    int t = arr[i]; arr[i] = arr[j]; arr[j] = t;
}

/* פלינדרום */
int isPal(int* arr, int size) {
    for (int i = 0; i < size / 2; i++)
        if (arr[i] != arr[size - 1 - i]) return 0;
    return 1;
}

/* שכיחות: ערכים בטווח 0..9 */
int cnt[10] = {0};
for (int i = 0; i < size; i++) cnt[arr[i]]++;

/* שני מצביעים: זוג שסכומו k במערך ממוין */
int lo = 0, hi = size - 1;
while (lo < hi) {
    int s = arr[lo] + arr[hi];
    if (s == k) return 1;
    if (s < k) lo++; else hi--;
}
return 0;
```

## מלכודות נפוצות
> 🪤 `arr[size]` כבר מחוץ למערך. גם `arr[i+1]` בתוך לולאה שרצה עד `size-1`.

> 🪤 במערך עזר: שוכחים לאפס, או שטווח הערכים לא מתאים לגודל המערך.

> 🪤 הדרישה "ללא מערך עזר" או "`O(1)` זיכרון" פוסלת מערך ספירה. הדרישה "`O(n)`" פוסלת לולאה בתוך לולאה.

> 🪤 מקרי קצה: מערך באורך 1, כל האיברים שווים, אין תשובה בכלל (מה מחזירים?).

## דוגמה פתורה
"האיבר שמופיע הכי הרבה פעמים, כשהאיברים בין 0 ל-9":
```c
int mostFrequent(int* arr, int size) {
    int cnt[10] = {0}, best = 0;
    for (int i = 0; i < size; i++) cnt[arr[i]]++;
    for (int v = 1; v < 10; v++)
        if (cnt[v] > cnt[best]) best = v;
    return best;
}
```
הזמן `O(n + 10)`, כלומר `O(n)`. פתרון עם שתי לולאות מקוננות שסופרות כל איבר מחדש היה `O(n^2)`.
