# gcd, lcm ומחלקים

## מה המבחן שואל
כתיבת פונקציה שמחשבת מחלק משותף מקסימלי (gcd), כפולה משותפת מינימלית (lcm), מחלקים של מספר, בדיקת ראשוניות, או מספרים מיוחדים (מושלם, ידידותי, ארמסטרונג). לעיתים נדרש פתרון יעיל יותר מבדיקה של כל המספרים עד `n`.

## הרעיונות המרכזיים
- אלגוריתם אוקלידס: `gcd(a, b) = gcd(b, a % b)` ועוצרים כש-`b == 0`. זמן `O(log min(a, b))`.
- `lcm(a, b) = a / gcd(a, b) * b`. מחלקים לפני שמכפילים כדי להימנע מגלישה.
- מחלקים מגיעים בזוגות: אם `d` מחלק את `n` אז גם `n / d`. לכן מספיק לעבור עד `sqrt(n)`.
- ראשוני: גדול מ-1 ואין לו מחלק מ-2 עד `sqrt(n)`. בלולאה: `i * i <= n`.
- מספר מושלם: סכום המחלקים שלו (בלי עצמו) שווה אליו, למשל 6 ו-28. שני מספרים ידידותיים: סכום המחלקים של כל אחד שווה לשני.
- מספר ארמסטרונג (חזקה מושלמת): סכום ספרותיו בחזקת מספר הספרות שווה למספר עצמו, למשל 153.

## תבניות C מדויקות
```c
int gcd(int a, int b) {
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

int gcdRec(int a, int b) { return b == 0 ? a : gcdRec(b, a % b); }

int lcm(int a, int b) { return a / gcd(a, b) * b; }

int isPrime(int n) {
    if (n < 2) return 0;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return 0;
    return 1;
}

/* סכום מחלקים אמיתיים, עד sqrt(n) */
int divSum(int n) {
    int s = 1;                       /* 1 מחלק (עבור n > 1) */
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) {
            s += i;
            if (i != n / i) s += n / i;   /* לא לספור שורש פעמיים */
        }
    return s;
}
```

## מלכודות נפוצות
> 🪤 `lcm = a * b / gcd` עלול לגלוש ב-`int`. עדיף `a / gcd * b`.

> 🪤 `divSum` מוגדרת עבור `n > 1`. עבור `n == 1` הסכום הנכון של מחלקים אמיתיים הוא 0.

> 🪤 לולאת ראשוניות עד `n` במקום `sqrt(n)` נכונה אבל איטית, ובמבחן עם דרישת סדר גודל היא נפסלת.

> 🪤 ספירה כפולה של `sqrt(n)` כשהמספר ריבוע מושלם (36: המחלק 6).

> 🪤 `i * i <= n` יכול לגלוש עבור `n` גדול מאוד. בתרגילי מבחן נהוג להשתמש בו.

## דוגמה פתורה
`gcd(48, 18)`: `48 % 18 = 12`, אז `(18, 12)`. `18 % 12 = 6`, אז `(12, 6)`. `12 % 6 = 0`, אז `(6, 0)` ומחזירים 6. לכן `lcm(48, 18) = 48 / 6 * 18 = 144`.
