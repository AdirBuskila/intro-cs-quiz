# סדר גודל

## מה המבחן שואל
נותנים קוד ושואלים מה סדר הגודל שלו, או מבקשים לכתוב פתרון בסדר גודל מסוים (`O(n)`, `O(log n)`, `O(n log n)`) ולעיתים גם בזיכרון `O(1)`. סיבוכיות זמן נמדדת בגודל הקלט (`n`) ובמספר הפעולות הבסיסיות.

## הרעיונות המרכזיים
- סדרי גודל, מהמהיר לאיטי: `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n^2)`, `O(2^n)`.
- פעולות פשוטות (חשבון, השוואה, השמה, גישה לאיבר) הן `O(1)`.
- לולאה שרצה `n` פעמים: `O(n)`. שתי לולאות מקוננות על `n`: `O(n^2)`. שתי לולאות עוקבות (לא מקוננות): `O(n) + O(n) = O(n)`.
- לולאה שמכפילה או חוצה את המשתנה בכל חזרה (`i *= 2`, `n /= 2`): `O(log n)`.
- לולאה פנימית שתלויה בחיצונית: סוכמים. `for i: for j<i` נותן `1 + 2 + ... + n`, כלומר `O(n^2)`.
- רקורסיה: מספר הקריאות כפול העבודה בכל אחת. קריאה אחת עם `n-1` היא `O(n)`; חצייה בכל קריאה (חיפוש בינארי) היא `O(log n)`; שתי קריאות עם `n-1` (פיבונאצ'י נאיבי) היא `O(2^n)`; שתי קריאות עם `n/2` ועוד מיזוג לינארי (מיון מיזוג) היא `O(n log n)`.
- זיכרון: מערך עזר בגודל `n` הוא `O(n)` זיכרון. מעמק הרקורסיה גם הוא נספר (מחסנית).
- מקרה גרוע הוא ברירת המחדל, אלא אם נשאלים במפורש על מקרה ממוצע או טוב.

## תבניות C מדויקות
```c
/* O(n) */
for (int i = 0; i < n; i++) sum += arr[i];

/* O(log n): חוצים את הטווח */
for (int m = n; m > 0; m /= 2) count++;

/* O(n^2) */
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) pairs++;

/* O(n log n): לולאה חיצונית n, פנימית log n */
for (int i = 0; i < n; i++)
    for (int j = 1; j < n; j *= 2) work++;

/* O(n): הפנימית תלויה אך סכומה הכולל לינארי (שני מצביעים) */
int lo = 0, hi = n - 1;
while (lo < hi) { if (cond) lo++; else hi--; }
```

## מלכודות נפוצות
> 🪤 לולאה מקוננת אינה תמיד `O(n^2)`: אם הפנימית רצה מספר קבוע של פעמים, או אם סך התקדמות המשתנים הוא `n`, הכול `O(n)`.

> 🪤 `strlen` או חישוב אחר בתוך תנאי לולאה: הוא `O(n)` בכל חזרה ולכן הלולאה `O(n^2)`.

> 🪤 לא מוותרים על קבועים בטעות: `O(2n)` ו-`O(n)` שווים, אבל `O(n^2)` ו-`O(n)` שונים.

> 🪤 חיפוש בינארי הוא `O(log n)` רק על מערך ממוין. אם צריך למיין קודם, המיון (`O(n log n)`) שולט.

> 🪤 העתקת מערך בכל קריאה רקורסיבית מוסיפה `O(n)` לכל קריאה.

## דוגמה פתורה
מה סדר הגודל?
```c
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < n; j++)
        x++;
```
הלולאה החיצונית רצה בערך `log n` פעמים (`i` מוכפל ב-2), והפנימית `n` פעמים בכל אחת. סך הכול `O(n log n)`.
