# מטריצות

## מה המבחן שואל
כתיבת פונקציה על מטריצה `N x N` או `rows x cols`: סכום שורה/עמודה/אלכסון, בדיקת תכונה כמו ריבוע קסם (כל השורות, העמודות והאלכסונים בעלי אותו סכום), חיפוש בשורות ממוינות, או סיבוב והזזה של שורה. השאלות בודקות סדר פעולות ואינדקסים נכונים.

## הרעיונות המרכזיים
- `int mat[ROWS][COLS]` שמורה שורה אחרי שורה בזיכרון. `mat[i][j]` היא שורה `i`, עמודה `j`.
- כשמעבירים מטריצה לפונקציה, חובה לציין את מספר העמודות: `int mat[][COLS]`. את מספר השורות מעבירים כפרמטר.
- מעבר על כל התאים: שתי לולאות מקוננות, `O(rows * cols)`.
- אלכסון ראשי: `i == j`. אלכסון משני: `i + j == N - 1`.
- אם כל שורה ממוינת, אפשר לחפש בכל שורה בחיפוש בינארי: `O(rows * log cols)`. אם המטריצה ממוינת גם לאורך עמודות, אפשר לחפש מהפינה (למעלה ימינה): `O(rows + cols)`.
- ריבוע קסם: מחשבים סכום של שורה אחת כייחוס, ובודקים את כל השאר מולו.

## תבניות C מדויקות
```c
#define N 4

/* סכום אלכסונים */
int d1 = 0, d2 = 0;
for (int i = 0; i < N; i++) {
    d1 += mat[i][i];
    d2 += mat[i][N - 1 - i];
}

/* סכום שורה i ועמודה j */
int rowSum = 0, colSum = 0;
for (int k = 0; k < N; k++) {
    rowSum += mat[i][k];
    colSum += mat[k][j];
}

/* חיפוש מהפינה במטריצה ממוינת בשורות ובעמודות */
int i = 0, j = N - 1;
while (i < N && j >= 0) {
    if (mat[i][j] == key) return 1;
    if (mat[i][j] > key) j--; else i++;
}
return 0;

/* הזזה ימינה של שורה אחת, מחזורית */
int last = mat[r][N - 1];
for (int c = N - 1; c > 0; c--) mat[r][c] = mat[r][c - 1];
mat[r][0] = last;
```

## מלכודות נפוצות
> 🪤 בלבול בין `mat[i][j]` ל-`mat[j][i]`: שורה היא האינדקס הראשון.

> 🪤 מטריצה שנשלחת בלי `COLS` קבוע: הקומפיילר לא יידע לחשב כתובת, והקוד לא יתקמפל.

> 🪤 הזזת שורה בכיוון הלא נכון דורסת ערכים לפני שנשמרו. שומרים את האיבר שנופל מהקצה מראש.

> 🪤 אלכסון משני: `N - 1 - i`, לא `N - i`.

> 🪤 בבדיקת ריבוע קסם לא לשכוח את שני האלכסונים, ולא להשוות לסכום ששמור מקדימה בלי לחשב אותו מהשורה הראשונה.

## דוגמה פתורה
"האם כל שורות המטריצה בעלות אותו סכום?"
```c
int equalRows(int mat[][N]) {
    int ref = 0;
    for (int j = 0; j < N; j++) ref += mat[0][j];
    for (int i = 1; i < N; i++) {
        int s = 0;
        for (int j = 0; j < N; j++) s += mat[i][j];
        if (s != ref) return 0;
    }
    return 1;
}
```
סכום השורה הראשונה משמש כייחוס. הזמן `O(N^2)`, כלומר לינארי בגודל הקלט.
