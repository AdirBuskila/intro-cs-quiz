# תנאים ולולאות

## מה המבחן שואל
כמעט כל שאלה במבחן מכילה לולאה. הנפוץ ביותר: מעבר על ספרות של מספר, מעבר על מערך עם מונה או צובר, ובדיקת תנאי עם מספר תנאים משולבים. מבקשים לכתוב את הלולאה, או לעקוב אחרי הרצה ולומר כמה פעמים היא רצה.

## הרעיונות המרכזיים
- `if / else if / else`: רק הענף הראשון שהתנאי שלו אמת מתבצע.
- `&&` ו-`||` מחושבים בקיצור דרך: אם אפשר להכריע מהאופרנד השמאלי, הימני לא נבדק. זה משמש כדי למנוע גישה מחוץ למערך.
- `for` כשידוע מספר החזרות, `while` כשהעצירה תלויה בתנאי.
- צובר (accumulator): משתנה שמתחיל בערך ניטרלי (0 לסכום, 1 למכפלה) ומתעדכן בכל חזרה.
- `break` יוצא מהלולאה הפנימית ביותר; `continue` מדלג לחזרה הבאה. `switch` דורש `break` בסוף כל `case`.

## תבניות C מדויקות
```c
/* ספרות של מספר, מהאחרונה לראשונה */
while (n > 0) {
    int d = n % 10;
    /* ... שימוש ב-d ... */
    n /= 10;
}

/* מקסימום במערך */
int max = arr[0];
for (int i = 1; i < size; i++)
    if (arr[i] > max) max = arr[i];

/* בדיקה בלי לצאת מהמערך */
if (i < size && arr[i] == x) { /* ... */ }
```

## מלכודות נפוצות
> 🪤 נקודה-פסיק אחרי `for (...)` או `if (...)` הופכת את הגוף לריק.

> 🪤 `for (i = 0; i <= size; i++)` קורא תא אחד מעבר לסוף המערך (off by one).

> 🪤 לולאה שמשנה את המשתנה שהיא עוברת עליו: אם משתמשים ב-`n` כדי לחשב ספרות וגם צריכים אותו אחר כך, שומרים עותק (`int copy = n;`).

> 🪤 `switch` בלי `break`: הביצוע ממשיך (fall through) לענף הבא.

## דוגמה פתורה
סכום ספרות של מספר שלם חיובי:
```c
int digitSum(int n) {
    int s = 0;
    while (n > 0) {
        s += n % 10;
        n /= 10;
    }
    return s;
}
```
עבור 305: הספרה 5, אחר כך 0, אחר כך 3, והסכום 8. הלולאה רצה מספר פעמים כמספר הספרות.
