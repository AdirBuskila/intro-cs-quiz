# רקורסיה

## מה המבחן שואל
כמעט בכל מבחן יש שאלה אחת לפחות: (א) עקבו אחרי רקורסיה ואמרו מה היא מחזירה או מה היא מדפיסה, או (ב) כתבו פונקציה רקורסיבית, לעיתים עם איסור על לולאות או על פונקציות עזר, לעיתים עם דרישה לסדר גודל.

## הרעיונות המרכזיים
- כל פונקציה רקורסיבית צריכה מקרה בסיס (עוצר) וצעד רקורסיבי שמקטין את הבעיה לעבר מקרה הבסיס.
- קריאה = כרטיס חדש במחסנית עם עותק משלו של הפרמטרים. הערכים חוזרים בסדר הפוך לקריאות.
- כשיש `printf` לפני הקריאה, ההדפסה בסדר הקריאות. כשהוא אחריה, בסדר ההפוך.
- ספרות של מספר: `n % 10` הספרה האחרונה, `n / 10` שאר המספר.
- מערך ברקורסיה: מעבירים אינדקס או גודל, ומקטינים אותו בכל קריאה. אפשר גם להעביר `arr + 1` ו-`size - 1`.
- שתי קריאות רקורסיביות באותה פונקציה (כמו פיבונאצ'י) הן בדרך כלל סדר גודל מעריכי.

## תבניות C מדויקות
```c
int digitCount(int n) {
    if (n < 10) return 1;                 /* בסיס */
    return 1 + digitCount(n / 10);        /* צעד */
}

/* מערך: האם ממוין עולה */
int isAscending(int* arr, int size) {
    if (size <= 1) return 1;
    if (arr[0] > arr[1]) return 0;
    return isAscending(arr + 1, size - 1);
}

/* מחרוזת: ספירת תו */
int count(char* s, char c) {
    if (*s == '\0') return 0;
    return (*s == c) + count(s + 1, c);
}
```

## מלכודות נפוצות
> 🪤 מקרה בסיס חסר או כזה שלא מושג (למשל `n == 0` כשהפרמטר מקטין ב-2 ויכול לדלג מעליו): רקורסיה אינסופית וקריסה.

> 🪤 לשכוח `return` לפני הקריאה הרקורסיבית: הערך שמוחזר הוא זבל.

> 🪤 בעקיבה: כתבו טבלה של קריאות (פרמטרים) ועוד טבלה של ערכים מוחזרים. אל תערבבו בין סדר הכניסה לסדר היציאה.

> 🪤 משתנה גלובלי או `static` נשמר בין קריאות. פרמטר רגיל לא.

## דוגמה פתורה
מה מדפיסה `f(3)`?
```c
void f(int n) {
    if (n == 0) return;
    printf("%d ", n);
    f(n - 1);
    printf("%d ", n);
}
```
קריאות: `f(3)` מדפיסה 3 ואז קוראת ל-`f(2)` שמדפיסה 2 ואז קוראת ל-`f(1)` שמדפיסה 1, `f(0)` חוזרת. בחזרה, מודפסים 1, 2, 3. הפלט: `3 2 1 1 2 3`.
