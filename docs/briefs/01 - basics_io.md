# משתנים, קלט/פלט וביטויים

## מה המבחן שואל
שאלות הקוד במבחן כמעט אף פעם לא עוסקות ב-`scanf` לשמו, אבל כל פתרון נשען על חשבון נכון עם `int`, על חילוק שלמים ועל שארית. במבחן מבקשים לרוב לעקוב אחרי קטע קוד ולכתוב מה יודפס, או לכתוב פונקציה קצרה שמחשבת ערך מספרי.

## הרעיונות המרכזיים
- טיפוסים: `int` (שלם), `float`/`double` (ממשי), `char` (תו, בפועל מספר קטן לפי ASCII).
- `/` בין שני שלמים הוא חילוק שלם (חותך את החלק העשרוני). `%` נותן את השארית.
- מספיק שאחד מהאופרנדים יהיה ממשי כדי שהחילוק יהיה ממשי.
- `x++` מחזיר את הערך הישן ואז מגדיל; `++x` מגדיל ואז מחזיר.
- ב-`scanf` שולחים כתובת של משתנה (`&x`), ובמחרוזת לא צריך `&`.

## תבניות C מדויקות
```c
int x;
scanf("%d", &x);          /* int: %d */
double d;
scanf("%lf", &d);         /* double בקלט: %lf */
printf("%d %.2f %c\n", x, d, 'a');

double avg = (double)sum / n;   /* המרה לפני החילוק */
int last  = num % 10;           /* ספרה אחרונה */
int rest  = num / 10;           /* חיתוך הספרה האחרונה */
```

## מלכודות נפוצות
> 🪤 `5 / 2` שווה 2, ו-`(double)(5 / 2)` שווה 2.0. ההמרה חייבת לקרות לפני החילוק: `(double)5 / 2`.

> 🪤 `=` מציב ו-`==` משווה. `if (x = 3)` תמיד אמת.

> 🪤 `%` עם מספר שלילי נותן שארית שלילית ב-C (`-7 % 3` הוא `-1`). בשאלות מבחן בדרך כלל המספרים חיוביים, אבל כדאי לשים לב.

> 🪤 משתנה מקומי שלא אותחל מכיל זבל. אל תניחו שהוא 0.

## דוגמה פתורה
מה מדפיס הקטע?
```c
int a = 7, b = 2;
double r = a / b;
printf("%.1f %d", r, a++ + ++b);
```
`a / b` הוא חילוק שלם, 3, ולכן `r` הוא 3.0. בביטוי האחרון `a++` נותן 7 (ואז `a` נהיה 8), ו-`++b` נותן 3. הסכום 10. הפלט: `3.0 10`.
