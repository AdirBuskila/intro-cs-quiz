# מחרוזות

## מה המבחן שואל
כתיבת פונקציה על מחרוזת (`char*`): ספירת תווים, בדיקת תקינות לפי חוקים, פלינדרום, הפיכה, מרחקים בין תווים, ולעיתים בשילוב רקורסיה או הקצאה דינמית. צריך לחשוב על `'\0'` כסימן סוף.

## הרעיונות המרכזיים
- מחרוזת היא מערך `char` שמסתיים בתו הריק `'\0'` (ערך ASCII 0). בלעדיו זה רק מערך תווים.
- `"Hello"` תופסת 6 בתים. מערך שמכיל מחרוזת צריך מקום גם לתו הריק.
- תווים הם מספרים: `'a' + 1 == 'b'`, `ch - '0'` ממיר ספרה לערך, `ch - 'a'` נותן אינדקס של אות בא"ב.
- פונקציות ב-`<string.h>`: `strlen` (בלי ה-`'\0'`), `strcpy(dst, src)`, `strcat(dst, src)`, `strcmp(a, b)` (0 אם שווים, חיובי אם `a` גדולה יותר, שלילי אם קטנה), `strchr(s, c)` ו-`strstr(s, sub)` שמחזירות מצביע למקום המציאה או `NULL`.
- `char* s = "hi";` מצביע למחרוזת קבועה שאי אפשר לשנות. `char s[] = "hi";` הוא עותק שאפשר לשנות.
- קלט: `fgets(buf, sizeof(buf), stdin)` קורא שורה כולל רווחים, ולעיתים משאיר `'\n'` בסוף. `scanf("%s", buf)` קורא עד רווח ואינו מגן על הגבולות.

## תבניות C מדויקות
```c
/* מעבר על מחרוזת */
for (int i = 0; s[i] != '\0'; i++) { /* ... */ }
while (*s) { /* ... */ s++; }

/* פלינדרום עם שני אינדקסים */
int isPal(char* s) {
    int i = 0, j = (int)strlen(s) - 1;
    while (i < j) {
        if (s[i] != s[j]) return 0;
        i++; j--;
    }
    return 1;
}

/* תדירות אותיות */
int cnt[26] = {0};
for (int i = 0; s[i]; i++)
    if (s[i] >= 'a' && s[i] <= 'z') cnt[s[i] - 'a']++;

/* עותק דינמי */
char* copy = (char*)malloc(strlen(s) + 1);
strcpy(copy, s);

/* הסרת '\n' אחרי fgets */
s[strcspn(s, "\n")] = '\0';
```

## מלכודות נפוצות
> 🪤 `malloc(strlen(s))` חסר בית אחד ל-`'\0'`. תמיד `strlen(s) + 1`.

> 🪤 `strcpy` ו-`strcat` לא בודקות גבולות. היעד חייב להיות גדול מספיק.

> 🪤 `s1 == s2` משווה כתובות. להשוואת תוכן: `strcmp(s1, s2) == 0`.

> 🪤 בניית מחרוזת חדשה ושכחת `'\0'` בסוף: ההדפסה תמשיך אל זבל.

> 🪤 `strlen` בתנאי לולאה שמשנה את המחרוזת מחושב מחדש בכל חזרה (`O(n^2)`).

> 🪤 `'a'` (תו) ו-`"a"` (מחרוזת של שני בתים) הם דברים שונים.

## דוגמה פתורה
"האם המחרוזת מתחילה באות קטנה ומכילה רק אותיות קטנות ורווחים?"
```c
int valid(char* s) {
    if (s[0] < 'a' || s[0] > 'z') return 0;
    for (int i = 1; s[i] != '\0'; i++)
        if (!(s[i] == ' ' || (s[i] >= 'a' && s[i] <= 'z')))
            return 0;
    return 1;
}
```
במחרוזת ריקה `s[0]` הוא `'\0'`, שאינו אות, ולכן מוחזר 0 בלי לעבור על המחרוזת. הלולאה מתחילה מאינדקס 1.
