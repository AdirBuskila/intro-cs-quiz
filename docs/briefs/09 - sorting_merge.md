# מיון ומיזוג

## מה המבחן שואל
לרוב לא "ממשו מיון", אלא שימוש ברעיון: מיזוג שני מערכים ממוינים, חלוקה לפי תנאי (זוגיים לפני אי-זוגיים), מיון ספירה לטווח קטן, או חיפוש ה-`k` הקטנים. שואלים גם מה סדר הגודל של האלגוריתם.

## הרעיונות המרכזיים
- מיזוג (`merge`): שני מערכים ממוינים, שני אינדקסים, בכל צעד מעתיקים את הקטן מבין שני הראשים. זמן `O(n + m)`.
- מיון מיזוג (merge sort): מחלקים לחצאים, ממיינים כל חצי ברקורסיה, ממזגים. זמן `O(n log n)`, זיכרון עזר `O(n)`.
- מיון מהיר (quick sort): בוחרים ציר (pivot), מחלקים סביבו, ממיינים כל צד. ממוצע `O(n log n)`, במקרה הגרוע `O(n^2)`.
- חלוקה (partition) עם שני מצביעים: אחד מתקדם משמאל עד שפוגש איבר שלא שייך, השני מימין, מחליפים. זמן `O(n)` ובלי זיכרון נוסף.
- מיון ספירה: כשהערכים בטווח קטן וידוע (למשל ספרות 0 עד 9). סופרים הופעות ואז כותבים מחדש. זמן `O(n + range)`.
- מיון בועות, בחירה והכנסה הם `O(n^2)`.

## תבניות C מדויקות
```c
/* מיזוג שני מערכים ממוינים a (גודל n) ו-b (גודל m) אל res */
void merge(int* a, int n, int* b, int m, int* res) {
    int i = 0, j = 0, k = 0;
    while (i < n && j < m)
        res[k++] = (a[i] <= b[j]) ? a[i++] : b[j++];
    while (i < n) res[k++] = a[i++];
    while (j < m) res[k++] = b[j++];
}

/* זוגיים לפני אי-זוגיים, במקום, O(n) */
int lo = 0, hi = n - 1;
while (lo < hi) {
    while (lo < hi && arr[lo] % 2 == 0) lo++;
    while (lo < hi && arr[hi] % 2 != 0) hi--;
    if (lo < hi) { int t = arr[lo]; arr[lo] = arr[hi]; arr[hi] = t; }
}

/* מיון ספירה לערכים 0..9 */
int cnt[10] = {0}, k = 0;
for (int i = 0; i < n; i++) cnt[arr[i]]++;
for (int v = 0; v < 10; v++)
    for (int c = 0; c < cnt[v]; c++) arr[k++] = v;
```

## מלכודות נפוצות
> 🪤 במיזוג שוכחים לסיים את הזנב של המערך שנשאר. שתי לולאות ה-`while` האחרונות נחוצות.

> 🪤 מיזוג דורש שהקלט ממוין. מיזוג של מערך לא ממוין לא ייתן מערך ממוין.

> 🪤 במיון מיזוג רקורסיבי, חישוב אמצע `(low + high) / 2`, והטווח הוא `[low, mid]` ו-`[mid+1, high]`. טווח חופף יוצר רקורסיה אינסופית.

> 🪤 מיון ספירה מתאים לטווח מוגבל בלבד. לערכים כלליים הוא לא ישים.

> 🪤 הדרישה `O(n)` ללא זיכרון נוסף מכוונת לרוב לחלוקה עם שני מצביעים.

## דוגמה פתורה
ממזגים `a = {1, 4, 9}` ו-`b = {2, 3, 10, 11}`: משווים 1 ו-2, לוקחים 1. משווים 4 ו-2, לוקחים 2. אחר כך 3. אחר כך 4 מול 10, לוקחים 4. אחר כך 9. `a` נגמר, והזנב של `b` (10, 11) מועתק. התוצאה: `1 2 3 4 9 10 11`. מספר ההשוואות לכל היותר `n + m - 1`, כלומר הזמן `O(n + m)`.
