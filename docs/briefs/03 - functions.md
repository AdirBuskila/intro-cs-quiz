# פונקציות

## מה המבחן שואל
כמעט כל שאלה היא "כתבו פונקציה" עם חתימה נתונה. מעריכים אם הפונקציה מקבלת את הפרמטרים הנכונים, מחזירה ערך מהטיפוס הנכון, ומשתמשת בפונקציות עזר כשמותר (לרוב ניתן לכתוב פונקציית עזר משלכם אם לא נאסר).

## הרעיונות המרכזיים
- חתימה: טיפוס מוחזר, שם, רשימת פרמטרים. `void` אומר שאין ערך מוחזר.
- העברה by value: הפונקציה מקבלת עותק, ושינוי בו לא משפיע על המקור.
- כדי לשנות משתנה של הקורא, מעבירים את כתובתו (מצביע). מערך מועבר תמיד כמצביע לאיבר הראשון, ולכן שינוי איבריו כן נראה אצל הקורא.
- משתנה מקומי חי רק בזמן הריצה של הפונקציה. אסור להחזיר מצביע למשתנה מקומי.
- פונקציה צריכה להצהיר (prototype) לפני השימוש בה אם היא מוגדרת אחרי `main`.

## תבניות C מדויקות
```c
int max2(int a, int b) { return a > b ? a : b; }

void swap(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}
/* קריאה: swap(&x, &y); */

/* מערך כפרמטר: גודל מועבר בנפרד */
int sum(int arr[], int size);   /* זהה ל: int* arr */
```

## מלכודות נפוצות
> 🪤 `swap(int a, int b)` לא מחליפה כלום אצל הקורא.

> 🪤 בתוך פונקציה, `sizeof(arr)` של פרמטר מערך נותן גודל מצביע (4 או 8), לא גודל המערך. תמיד מקבלים `size` כפרמטר.

> 🪤 פונקציה עם ערך מוחזר שלא מחזירה בכל מסלול: התנהגות לא מוגדרת. בודקים שיש `return` בסוף.

> 🪤 החזרת מערך מקומי (`int arr[10]; return arr;`) מחזירה כתובת של זיכרון שכבר שוחרר.

## דוגמה פתורה
"כתבו פונקציה שמחזירה את מספר הזוגיים במערך":
```c
int countEven(int* arr, int size) {
    int c = 0;
    for (int i = 0; i < size; i++)
        if (arr[i] % 2 == 0) c++;
    return c;
}
```
חזרה ערך בודד, אז אין צורך במצביע. אם היו צריכים להחזיר גם את המקסימום, היו מעבירים עוד פרמטר מסוג `int*`.
