# מצביעים וזיכרון דינמי

## מה המבחן שואל
מבקשים להקצות מערך דינמי ולהחזיר אותו, לשחרר זיכרון נכון, ולעבוד עם מצביעים כפרמטרים. שאלות הבנה: מה מדפיס קטע עם `*`, `&` וחשבון מצביעים, או איפה יש דליפה או שחרור כפול.

## הרעיונות המרכזיים
- מצביע הוא משתנה שמכיל כתובת. `&x` היא הכתובת של `x`, ו-`*p` הוא הערך שבכתובת.
- `a[0] == *a`, ו-`a[i] == *(a+i)`. חיבור `i` למצביע מקדם אותו ב-`i` איברים (לא בתים).
- חשבון מצביעים: מותר לחבר ולחסר מספר שלם, ולחסר שני מצביעים מאותו מערך. חיבור שני מצביעים או כפל אסורים.
- `sizeof` של מצביע קבוע (4 או 8 בתים) ואינו תלוי בטיפוס שאליו הוא מצביע. `sizeof` של מערך הוא גודלו בבתים.
- זיכרון דינמי חי ב-heap עד ש-`free` ישחרר אותו. `malloc(n * sizeof(int))` לא מאפס, ו-`calloc(n, sizeof(int))` מאפס.
- הקצאה יכולה להיכשל והמצביע יהיה `NULL`. בודקים לפני שימוש (או `assert`).
- `realloc(p, newBytes)` משנה גודל הקצאה, עשוי להחזיר כתובת חדשה, ומשחרר את הישנה בעצמו.

## תבניות C מדויקות
```c
int* arr = (int*)malloc(n * sizeof(int));
if (arr == NULL) return NULL;
/* ... שימוש ... */
free(arr);
arr = NULL;

int* z = (int*)calloc(n, sizeof(int));   /* מאופס */

/* הגדלה בטוחה */
int* tmp = (int*)realloc(arr, 2 * n * sizeof(int));
if (tmp == NULL) { free(arr); return NULL; }
arr = tmp;

/* מצביעים כפרמטרים: החזרת שני ערכים */
void minMax(int* a, int n, int* mn, int* mx);

/* מערך שנוצר בפונקציה והוחזר */
int* build(int n) {
    int* a = (int*)malloc(n * sizeof(int));
    if (a == NULL) return NULL;
    for (int i = 0; i < n; i++) a[i] = i;
    return a;                            /* הקורא עושה free */
}
```

## מלכודות נפוצות
> 🪤 `free` על מערך סטטי, `free` פעמיים על אותו מצביע, `free` על מצביע שהוזז (`p++`): כולם שגיאות. `free(NULL)` מותר.

> 🪤 דליפת זיכרון: הקצאה בלי `free`, או דריסת המצביע לפני השחרור.

> 🪤 `sizeof(arr)` על מצביע שהוקצה עם `malloc` נותן גודל מצביע ולא גודל ההקצאה. שומרים את `n` בנפרד.

> 🪤 שוכחים `* sizeof(type)` ומקצים מעט מדי בתים.

> 🪤 החזרת כתובת של משתנה מקומי: הזיכרון כבר לא תקף.

> 🪤 `if (p = NULL)` מציב במקום להשוות.

## דוגמה פתורה
מה מדפיס הקטע?
```c
int a[] = {10, 20, 30, 40};
int* p = a + 1;
printf("%d %d %d", *p, *(p + 2), p[-1]);
```
`p` מצביע ל-20. `*(p+2)` הוא 40, ו-`p[-1]` הוא `*(p-1)`, כלומר 10. הפלט: `20 40 10`.
